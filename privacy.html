Privacy Policy

Nox App  ·  Effective date: November 1, 2026

Nox App is single-user personal software. It is operated only by its own developer, on their own device, using their own Google Account. It has no other users and collects no data from anyone else.

1. Who this policy covers

This policy describes how Nox App ("the App") handles information obtained through Google APIs. The App is a private personal automation tool with exactly one user: its operator and developer. Because the App is not distributed and does not accept sign-ups, this policy exists to document the App's data practices rather than to govern a public service.

2. What Google user data the App accesses

The App requests the following Google API scopes, and uses them only as described:

  • Gmail (gmail.readonly, gmail.modify, gmail.send) — to read the operator's own inbox, sort and label messages, and send replies drafted by the operator.
  • Google Calendar (calendar) — to read the operator's own calendar and create or remove events on request.
  • Google Drive (drive.readonly) — read-only access to files the operator chooses to reference.
  • Google Contacts (contacts.readonly) — to look up names when organizing the operator's own inbox.
  • Google Sheets (spreadsheets) and Docs (documents.readonly) — to read and update documents in the operator's own account.

The App accesses only the account of its operator. It does not access, request, or process Google user data belonging to any other person.

3. How the data is used

Google user data is used solely to perform the tasks the operator requests — for example, listing unread mail, archiving promotional messages, or adding a flight to the calendar. Specifically, the App does not:

  • use Google user data for advertising, marketing, or profiling;
  • sell, rent, or trade Google user data to any third party;
  • use Google user data to train, fine-tune, or evaluate machine learning or AI models;
  • transfer Google user data to any external service, analytics provider, or data broker;
  • allow any human other than the operator to read Google user data — Google user data is never reviewed by third parties.

4. Storage and retention

Google user data is stored only on the operator's own machine. OAuth credentials and access tokens are kept in local files readable solely by the operator's user account. Retrieved email and calendar content is held in memory or in local working files only for as long as needed to complete the requested task, and is not retained in any external database, cloud storage bucket, or third-party system.

Credentials can be revoked at any time, which immediately and permanently ends the App's ability to access the account.

5. Sharing and disclosure

Google user data is not shared with anyone. The App transmits data only to Google's own API endpoints, over encrypted HTTPS connections, as required to perform its functions. No analytics, telemetry, crash reporting, or advertising services are integrated into the App.

6. Google API Services User Data Policy compliance

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. In particular, Google user data is used only to provide or improve the App's user-facing features, is not transferred to others except as necessary to provide those features, and is never used for serving advertisements.

7. Security

Access is protected by Google's OAuth 2.0 authorization framework. The App requests offline access so it can operate without repeated sign-in, and stores the resulting refresh token locally with filesystem permissions restricted to the operator's account. The operator is responsible for the physical and account security of the device on which the App runs.

8. Revoking access and deleting data

Access can be revoked at any time by either method:

  • Visiting myaccount.google.com/permissions and removing Nox App's access; or
  • Deleting the local OAuth token file from the operator's machine.

Revocation takes effect immediately. Because no Google user data is stored externally, there is no separate remote copy to delete — removing the local token and any local working files fully removes the App's data.

9. Children's privacy

The App is not directed to children and is not accessible to anyone other than its operator. It does not knowingly collect information from children.

10. Changes to this policy

If this policy changes, the revised version will be posted on this page with an updated effective date.

11. Contact

Questions about this policy can be raised through the project's issue tracker.
